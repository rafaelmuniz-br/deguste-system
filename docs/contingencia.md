# Plano de contingência (imprimir e deixar na cozinha)

**Quando usar:** o site não abre, o painel da cozinha não mostra pedidos, ou o Pix não confirma **e não dá para resolver em 5 minutos**. Objetivo: **nenhum cliente fica sem resposta e nenhum pedido se perde.**

## 1. Avisar os clientes (30 segundos)

- Trocar o status do **WhatsApp** e o **Instagram** (Stories) para: _"Estamos com uma instabilidade no site de pedidos. Faça seu pedido aqui pelo WhatsApp: (71) 99659-4032 😊"_
- Se der, **fechar a loja no site** (Admin → Loja → "Fechada agora") para ninguém pedir sem ser atendido. Se o admin também não abrir, peça ao **Rafael**.

## 2. Atender pelo WhatsApp (modo manual)

Para cada pedido, anotar **em papel** (uma folha por pedido, numerada `M1, M2, M3...` para não confundir com os números do sistema):

| Anotar | Exemplo |
| --- | --- |
| Número manual | M3 |
| Nome e telefone | Maria, 71 9xxxx-xxxx |
| Itens, escolhas e observações | Combo Smash (Smash + Burguer), sem cebola |
| Entrega (endereço + referência) ou retirada | Rua X, 10, Pituba |
| Total e forma de pagamento | R$ 35,79 – Pix na chave da loja |

- **Pix manual:** mandar a **chave Pix da loja** e pedir o comprovante antes de fazer o pedido. _(Preencher: chave Pix = ______________ , em nome de ______________.)_
- Conferir o **valor** no app do banco antes de começar a fazer.
- O preço vale o **cardápio atual**. Se estiver em dúvida, confira no site (ele costuma abrir para consulta mesmo quando os pedidos falham).

## 3. Entregas

- Passar ao entregador: número M, nome, telefone, endereço, referência. (Com o sistema fora, o link de rota não existe: use o Google Maps no celular.)

## 4. Quando o sistema voltar

1. **Não apague as folhas de papel**: guarde até o fim do dia.
2. Reabrir a loja no site (Admin → Loja → "Seguir os horários").
3. Avisar no WhatsApp/Instagram que o site voltou.
4. No fim do dia, passar os pedidos manuais para uma planilha (data, itens, total, forma de pagamento) para não sumirem dos números do mês. O Rafael pode lançá-los no sistema depois, se o Bruno quiser.
5. Abrir uma issue no GitHub contando o que aconteceu (ver [`runbook.md`](runbook.md), "Depois de qualquer incidente").

## 5. Impressora sem funcionar mas o sistema no ar

Não é contingência: siga o [`runbook.md`](runbook.md) (item 1). O painel da cozinha mostra todos os detalhes do pedido na tela.
